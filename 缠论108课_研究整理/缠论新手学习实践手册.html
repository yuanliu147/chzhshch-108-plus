开始之前：先定三件事，再学第一关

缠论不是指标合集，是一套从K线一路搭到买卖点的结构语言。顺序错了，后面全乱。

① 定一个操作级别，和一个看图周期

级别是走势的级别，周期是你看的K线图。两者不是一回事：用什么图与以什么级别操作没任何必然关系65课。新手先固定一个组合，例如「30分钟级别操作、5分钟图定位」，练熟再换。

② 统一价格精度

取个位还是取两位小数，会改变分型、笔和线段的划分（第59、81课）。开始前就定死：用软件默认的不复权或前复权价、固定小数位，全程不改。形态分析用一套价，实际成交另记一套价。

③ 准备一张「遮右练习」表

拿任意走势图，用纸或软件遮住右边，一根一根往右放。每放一根，写下：现在能确认什么、还只是候选、你会做什么动作。这是全手册唯一的通用练法，依据是第65课的当下性。

④ 记住三条边界

本手册的图全是人工合成示意，不是行情。原文说买卖点「必然赢利」是作者观点，本次没有回测，不作收益承诺。图上的转折位置、你当时能识别的位置、你实际成交的位置，是三件事，每关都会单独标出。

学习地图：一条线搭上去

第1关 包含处理→第2关 分型→第3关 笔→第4关 线段→第5关 中枢→第6关 级别→第7关 背驰→第8关 买卖点→实战流程

前一关不熟，不要进下一关。第4关（线段）是分水岭：它决定后面中枢和买卖点画得对不对。作者在第72课把理论分成形态学（结构）与动力学（力度），本手册第1—6关是形态学，第7关是动力学，第8关是两者结合。

第1关包含处理：把K线变成「有效K线」

目标：得到一张没有包含关系的K线图。后面所有定义都在这张图上做。

原文口径 · 第62、65课

只看K线的高低点，不分阴阳。相邻两根若一根的高低区间全在另一根范围内，就是包含关系，要合并：在向上时，把两K线的最高点当高点，而两K线低点中的较高者当成低点，这样就把两K线合并成一新的K线62课；当向下时，把两K线的最低点当低点，而两K线高点中的较低者当成高点，这样就把两K线合并成一新的K线62课。

合并必须按顺序：先用第1、2根K线的包含关系确认新的K线，然后用新的K线去和第三根比65课。因为包含关系，不符合传递律。

「向上 / 向下」不是这两根K线自己的事

包含关系本身没有方向：A的高低区间全在B里，和B全在A里，说的是同一件事。所以只盯着被包含的这两根，永远决定不了合并后该保留哪一端——必须往前借一个方向。这就是「明明只是包含，为什么还要分向上向下」的答案。

方向来自前面那根已经走完、且与它不构成包含的K线。第65课给了严格定义：假设，第n根K线满足第n根与第n+1根的包含关系，而第n根与第n-1根不是包含关系，那么如果……，那么称第n-1、n、n+1根K线是向上的；如果……，那么称第n-1、n、n+1根K线是向下的。65课

两处省略号就是两个比较式，翻成白话：

  • 把正在被包含的两根记作第n根、第n+1根；再往前找一根与第n根不构成包含的K线，记作第n-1根。g是高点、d是低点。
  • 第n根高点不低于第n-1根高点（gn≥gn-1）→ 这三根是向上的。
  • 第n根低点不高于第n-1根低点（dn≤dn-1）→ 这三根是向下的。
  • 两个条件不可能同时成立65课。若两个都不成立（高点更低、低点更高），说明第n根其实被第n-1根包含，与前提矛盾，要再往前找一根。

为什么要借这个方向：合并是要把噪音压掉、把正在推进的那一端留下来。向上时高点在推进，所以高点取较高者、低点也取较高者（把回撤出来的低点抬掉）；向下时低点在推进，所以两端都取较低者。方向借错了，就会把刚刚走出来的新极值抹掉，还可能让包含关系重新出现——下面「方向从哪里来」那张图用同一组数字给出了后果。

阴阳线、红绿柱在哪一步才用

包含处理只用高低点：这里不分阳线阴线，只看K线高低点62课。开盘价、收盘价、阳线阴线、成交量、MACD红绿柱，都不参与合并，也不参与分型、笔、线段的定义。

阴阳线第一次被用到，是第82课判断已经按高低点定出来的分型力度：如果第二根K线是长上影甚至就是直接的长阴，而第三根K线不能以阳线收在第二根K线区间的一半之上，那么该顶分型的力度就比较大82课。这是力度解读，不是结构判定，不能拿它回头改合并结果。

MACD红绿柱只出现在背驰力度的比较里（第24课：其对应的MACD红柱子面积明显小于A段的24课），属于第7关的动力学，与第1关的几何处理无关。

判定步骤

  1. 定方向：发现第n根与第n+1根包含后，往前找与第n根不构成包含的第n-1根（必须已走完）。gn≥gn-1 → 向上；dn≤dn-1 → 向下。比较的是第n根与第n-1根，不是新来的第n+1根，更不是阴阳。图最左端没有第n-1根时，起点方向要事先约定并写进日志。
  2. 从左到右逐根比较相邻两根：无包含就保留，进入下一根。
  3. 有包含就按上一步定出的方向合并成一根新K线，区间按原文口径改写：向上两端都取较高者，向下两端都取较低者。
  4. 拿这根新K线继续和下一根比，重复到图尾。得到的序列就是有效K线。
  5. 收尾自检：原文的目标是所有K线图都可以处理成没有包含关系的图形62课。若结果里还剩包含，先回头查方向借得对不对、顺序有没有乱。
什么时候才算确认

只有已经走出来的K线才能参与合并。盘中没走完的那根，高低点还会变，不能拿它定方向或合并。唯一的要求就是被分析的K线已经走出来65课。

练什么 · 通关标准

找一段100根K线，手工合并一遍，再和软件或自己的第二遍对照。每一处合并都要在旁边写下三个编号：第n-1根是谁、第n根与第n+1根是谁、用的是哪个比较式。通关标准：两遍结果完全一致；每处合并都能指出定方向的那根K线；遮住右边重做，已处理部分不变。

别踩的坑

把包含当传递、一次性全局合并；只盯着被包含的两根猜方向（方向要往前一根借）；用阳线阴线或MACD红绿柱判断方向；合并后保留原来那根大K线；盘中用未走完的K线合并。这些都会让后面所有结构错位。

第2关分型：顶和底的最小单位

目标：在有效K线上标出所有顶分型、底分型。分型是笔的端点候选。

原文口径 · 第62课

顶分型：第二K线高点是相邻三K线高点中最高的，而低点也是相邻三K线低点中最高的62课。底分型相反：中间根低点最低、高点也最低。顶分型的最高点叫「顶」，底分型的最低点叫「底」。

判定步骤

  1. 确认输入是第1关输出的有效K线（无包含关系）。
  2. 取相邻三根，检查中间根：高点最高且低点最高 → 顶分型；低点最低且高点最低 → 底分型。
  3. 标出顶（中间根高点）或底（中间根低点）。顶分型画向下箭头、底分型画向上箭头，一目了然（第77课的建议）。
  4. 相邻分型不能共用K线（结合律，第77课）。若两个候选分型共用K线，它们不能同时作为一笔的两端，交给第3关的成笔与剔除规则处理。
什么时候才算确认

第三根走完，分型才可知。分型成立不等于笔成立，更不等于买卖点成立。它只是「这里有一个候选转折」。

练什么 · 通关标准

在一张图上标满所有分型，然后遮右重放：每新增一根K线，只允许新增或撤销最右侧的候选分型，已确认的不能变。通关标准：能解释每一个被撤销的候选为什么撤销。

别踩的坑

只找三个高点里的最高价就当顶分型；跳过包含处理直接判；把分型当成买卖信号立刻下单；用盘中未走完的第三根提前确认。

第3关笔：把分型连成上下交替的折线

目标：把图唯一地分解成一顶一底相连的笔。笔是线段的构件。

原文口径 · 第62、77课

相邻的顶和底之间构成一笔，顶底之间的其他波动忽略。顶和底之间至少有一个K线不属于顶分型与底分型77课。还有一条价格条件：顶分型中最高那K线的区间至少要有一部分高于底分型中最低那K线的区间。

判定步骤（第77课）

  1. 确定所有符合标准的分型（第2关的输出）。
  2. 同类比较剔除：对于顶，前面的低于后面的，只保留后面的，前面那个可以X掉；对于底，前面的高于后面的，只保留后面的，前面那个可以X掉77课。注意这条只删「前面」：相等或前面更极端的（前顶不低于后顶、前底不高于后底）都先保留，交步骤三处理。
  3. 余下分型若相邻是一顶一底，且满足独立K线与价格区间条件，连成一笔。
  4. 若仍相邻同性（步骤二后仍顶挨顶、底挨底，此时必是相等或前面更极端）：取连续同类中最先一个——它必是这串里最高的顶或最低的底——与新出现的相反分型连笔，中间的同类全部X掉。
  5. 检查结果：笔必须上下交替，先底后顶是向上一笔，先顶后底是向下一笔。
什么时候才算确认

一笔的终点要等相反分型满足全部条件才确认。在此之前它只是候选端点，后面出现更低的底或更高的顶时会改。日志里记「候选笔」和「已确认笔」两种状态，并记改端点的原因。

练什么 · 通关标准

手工划一段200根K线的笔，再用第77课三步骤独立划第二遍。通关标准：两遍一致；每一笔都能指出独立K线是哪根；遮右重放时只改最右侧候选笔。

别踩的坑

把每个分型都连起来；用社区流传的「固定几根K线」当成笔标准（本地原文没有这个口径）；漏掉价格区间条件；同类分型不剔除就直接连。

第4关线段：用特征序列判断一段何时结束

目标：把笔组合成线段，并知道线段在哪里结束。这是全手册最难也最关键的一关。

原文口径 · 第65、67课

线段至少三笔，且线段的前三笔，必须有重叠的部分65课。以向上笔开始的线段记作 S1X1S2X2…（S向上笔、X向下笔），取其中向下笔 X1X2… 作为特征序列；向下开始的线段取向上笔。特征序列两相邻元素间没有重合区间，称为该序列的一个缺口67课——这不是K线跳空。对特征序列做包含处理后叫标准特征序列。

判定步骤

  1. 确认候选线段至少三笔、前三笔有重叠，且笔数为单数、两端分型性质相反。
  2. 提取特征序列：向上段取向下笔，向下段取向上笔。每个元素用它的高低区间当成一根K线。
  3. 对特征序列做包含处理，得到标准特征序列。向上段只找顶分型，向下段只找底分型。
  4. 看分型第1、2元素之间有没有缺口。无缺口 → 第一种情况，线段在该分型高（低）点结束。
  5. 有缺口 → 第二种情况：从该分型最高（低）点开始取反向笔序列，构造它的特征序列，严格做包含处理；出现相反分型才确认结束。后一特征序列不一定封闭前一特征序列相应的缺口，而且，第二个序列中的分型，不分第一二种情况，只要有分型就可以67课。
什么时候才算确认

出现特征序列分型只是线段结束的前提。第一种情况当场可定；第二种情况要等第二特征序列的分型，确认更晚。在确认之前，端点一律记「候选」。第78课补充：第二特征序列必须严格做包含处理，不适用第一种情况里「假设分界点两侧不能合并」的限制。

练什么 · 通关标准

找10段真实走势，手工划线段；再专门找3个「有缺口」的例子走第二种情况。通关标准：能说出每个线段终点属于第一还是第二种情况、依据是哪两个元素；遮右重放时候选端点的改动都有记录。

别踩的坑

一笔反向跌破就宣布线段结束；跳过特征序列直接用早期粗略讲法；第二种情况里无限递归区分第一二种；把第二特征序列的包含处理省掉；用不同价格精度划出不同结果却不记录。

第5关中枢：三段已完成次级别走势的重叠

目标：会算中枢区间，会分延伸、新生、扩展。中枢是买卖点的参照物。

原文口径 · 第17、18课

某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分，称为缠中说禅走势中枢17课。计算以前三个为准，且次级别的前三个走势类型都是完成的才构成该级别的缠中说禅走势中枢18课。区间＝下沿取三段低点最大值、上沿取三段高点最小值。

判定步骤

  1. 先在第6关的口径下确认「次级别走势已完成」。按第53课，本级别图上已完成的次级别走势就当成一条线段，只取高低点。
  2. 取连续三个已完成的次级别走势，写出各自高低区间，求共同重叠 → 中枢核心 [ZD, ZG]。
  3. 标出与中枢方向一致的Z走势段，算外围 GG、DD 与 G、D，和核心分开保存。
  4. 后续每段波动检查：仍触及核心 → 延伸；离开并形成不重叠的新同级中枢 → 新生（趋势）；新中枢外围波动触及旧中枢波动 → 扩展（更大级别中枢）。
  5. 中枢破坏的判据：一个次级别走势离开后，其后的次级别回抽不重新回到中枢内（第18课中枢定理三）。这正是第8关三买的结构基础。
什么时候才算确认

第三个次级别走势走完，中枢才成立。在此之前只是「候选重叠区」。中枢成立后随时可以延伸，也可以结束——「可以结束」不等于「已经结束」（第18课）。

练什么 · 通关标准

在一张图上框出所有中枢，标核心与外围两套边界，并给每个中枢贴标签：延伸／新生／扩展。通关标准：能解释每个标签的依据；拿掉外围框后三买判定不变。

别踩的坑

拿本级别三根K线当中枢；用未完成的次级别走势算重叠；把外围GG当成ZG去判三买；横盘久了就叫中枢、突破一根K线就叫中枢新生。

第6关级别与走势类型：显微镜怎么换

目标：知道自己在哪个级别说话，知道次级别在本级别眼里长什么样。

原文口径 · 第53、17课

级别像不同倍数的显微镜。当你用一个级别的显微镜时，就等于先把次级别的当成线段了53课。走势类型只有三种：上涨、下跌、盘整；只含一个该级别中枢的是盘整，至少两个依次同向中枢的是趋势（第17课）。

判定步骤

  1. 写下你的操作级别与看图周期，以及最低不可分解级别（第17课通常设1分钟或5分钟）。
  2. 在本级别图上，把已完成的次级别走势当成线段：只取它的高低点，不看内部。
  3. 用这些线段构造本级别中枢（第5关），再数中枢个数与方向 → 盘整或趋势。
  4. 需要精细定位时（背驰段、次级别回试），切换到次级别图去看；看完回到本级别下结论。
  5. 连接两个同级别中枢的走势是次级别以下级别（第18课中枢定理一），力度往往很大，缺口就是极端例子。
什么时候才算确认

「某级别走势已完成」要由该级别的结构条件确认，不能因为小级别看起来转折了就宣布大级别完成。小级别背驰触及不到本级别一类点时，本级别不操作，用二类点补充（第53课）。

练什么 · 通关标准

同一段行情，分别在5分钟、30分钟、日线图上各划一次结构，写出三者的对应关系。通关标准：能指出30分钟图上的哪一条线段对应5分钟图上的哪一段走势；换图后不改变已确认的本级别结论。

别踩的坑

把K线周期当成级别；在30分钟图上纠结1分钟内部波动；一下30分钟一下年线把自己换晕；用日线分型宣布月线底部完成。

第7关背驰：先认结构，再比力度

目标：分清趋势背驰与盘整背驰，会用MACD做辅助比较，会用区间套缩小范围。

原文口径 · 第27、24课

趋势背驰的前提：趋势，一定有至少两个同级别中枢27课，且背驰发生在至少第二个中枢之后。第一个中枢后的力度减弱只算盘整背驰。MACD是比较工具：A、B、C三段中B把黄白线回拉0轴附近，C段的走势类型完成时对应的MACD柱子面积（向上的看红柱子，向下看绿柱子）比A段对应的面积要小，这时候就构成标准的背弛24课。

判定步骤（MACD辅助，第24课）

  1. 先确认结构：A之前已有一个中枢，B是另一个中枢，A、B、C同处一个大趋势；B的中枢级别比A、C里的大。
  2. 看B是否把DIFF/DEA回拉到0轴附近。没有回拉，A与C不可比。
  3. 比较C段与A段的柱子面积：向上比红柱、向下比绿柱。C面积小于A → 背驰候选。
  4. 盘中估计：柱子伸长变慢时，作者的经验是把已出现面积乘2当作整段面积（第24课）。这是实时估计，不是公式，也不是已完成面积；日志里要把估计值与真实值分开记。
  5. 用区间套定位：在本级别背驰段里，切到次级别找它的背驰段，逐级缩小；每一层都用该层当时可确认的条件。
什么时候才算确认

进入背驰段不等于背驰成立（第43课）。背驰成立后也不是只剩「马上上涨」：第29课背驰—转折定理给出三条路——最后中枢级别扩展、更大级别盘整、该级别以上反趋势。参数一般取12、26、9；MACD与均线只能是一种辅助性工具25课，急涨与连续一字涨停另作处理。

练什么 · 通关标准

找5个趋势背驰和5个盘整背驰的例子，逐个写出A/B/C三段、B是否回拉0轴、面积比较结果、属于哪条后续路径。通关标准：不把「价格新低+指标不新低」直接当买点；能说出每个例子缺了哪个前提就不成立。

别踩的坑

第一个中枢后就喊趋势背驰；脱离结构只看指标背离；用未来走完的柱子面积宣称当时已知；把背驰当成必然立刻大涨；区间套用最终低点反推上层范围。

第8关三类买卖点：各回答一个结构问题

目标：知道每类点在等什么结构、什么时候可知、错了怎么退。卖点方向完全相反。

原文口径 · 第20、21、101课

一买＝该级别下跌趋势的背驰转折点。二买＝所谓第二类买点，就是第一类买点的次级别回抽结束后再次探底或回试的那个次级别走势的结束点101课。三买＝一个次级别走势向上离开中枢后，首次次级别回试低点不跌破ZG；必须是第一次20课，且离开与回试的走势类型都必须是完成的：这里说的走势类型，都必须是完成的。51课·署名回复。

类别买点条件卖点条件（镜像）最早何时可知
第一类下跌趋势（≥两个同级中枢）背驰的转折位置上涨趋势背驰的转折位置背驰段内次级别结构确认时；位置本身事后才完全清楚
第二类一买后次级别向上结束，再一个次级别向下结束一卖后次级别向下结束，再一个次级别向上结束回试的那个次级别走势完成时

判定步骤

  1. 先写级别。同一张图上不同级别的买卖点意义不同，不能混着喊。
  2. 一买：确认下跌趋势＋背驰（第7关），再等背驰段内的次级别转折结构。
  3. 二买：等一买后的次级别反弹走完，再等回试的次级别走势走完；记录它高于还是低于一买。
  4. 三买：确认中枢与ZG；确认离开段是完成的次级别走势；确认这是第一次回试；确认回试低点≥ZG。
  5. 小级别转大级别时本级别可能没有一买，用二买补充（第53课）；不要硬找不存在的一买。
  6. 下单前把四个时间写全：结构位置、首次可知、实际成交、最后修订。成交价按你的执行方案记，不按图上极值记。
什么时候才算确认

三类点都依赖「完成的次级别走势」。走势没走完，点就只是候选。三买确认后也不保证走趋势：第20课说也可能进入更大级别盘整，策略是一旦不能形成趋势就在盘整高点出掉。

练什么 · 通关标准

在历史图上只标三类点，不标其他买卖理由；每个点写全四个时间与依赖结构。通关标准：遮右重放时，已标点的可知时间不晚于结构完成时间；能指出哪些点是二买三买重合、哪些是二买低于一买。

别踩的坑

把任意突破回调当三买；要求二买必须高于一买；把一买二买三买当成价格依次升高的固定链条；用图上最低价当成交价；上涨趋势里还去找该级别一买二买。

实战流程：从选股到退出的一页清单

前八关练的是读图。这一节把读图变成动作。所有动作都要能回写到日志里。

选标的→定级别→画结构→等买点→下单→持有与短差→退出→复盘
  1. 选标的：先保证能持续交易、成交被承认、资金期限够长（第26课）。盘子太小、长期停牌、无法成交的品种不进练习池。
  2. 定级别：写下操作级别、看图周期、最低级别、价格精度。一次只做一个级别的主仓位。
  3. 画结构：按第1—6关顺序画：有效K线 → 分型 → 笔 → 线段 → 中枢 → 走势类型。候选与确认分开标。
  4. 等买点：只在预先设定的三类点上动手。不参与中枢震荡，只在预先设定的买卖点上买卖53课。二三买之间的震荡没有该级别买卖点，想参与只能用低级别点，那是另一套仓位。
  5. 下单：买多少、占总资金多少，事先研究好；介入就一次性买入，没信心就一股都不买（第31课）。记录实际成交时间与成交价。
  6. 持有与短差：买入后下跌，除非买入理由消失或出现严重坏形态，否则不抛；用留出的机动资金做短差降成本，但短差不能增加股票数量。
  7. 退出：出现该级别卖点就走。三买后若不能形成趋势，在盘整高点出掉（第20课）。背驰后的三条路径都要预案，不预设只涨不跌。
  8. 复盘：逐笔对照日志：结构位置、首次可知、实际成交、最后修订四个时间是否齐全；有没有把后来才知道的信息提前用进决策。

仓位与成本：第31课的最稳固基础

成本为0之前

目标是把成本变为0：途中用小级别短差，加上在约1倍升幅附近找一个大级别卖点出掉部分，收回全部投入。买股票，宁愿不断跌不断买，也绝对不往上加码31课。

成本为0之后

开始挣股票：每次短差上面抛了都全部回补，股数越来越多而成本仍为0，直到至少月线以上的大卖点一次性退出。负成本是历史现金流口径，不等于当前持仓没有风险：市值跌掉多少，财富就少多少。

机动资金

针对每只买入的股票，都要留部分机动的资金，例如1/1031课；每次短差，一定不能增加股票的数量。越跌越买指的是用机动资金做差价降成本，不是不断提高总仓位。

资金前提

资金必须长期无压力，不借钱加码，不交给别人管理。第31课的两个爆仓故事都是前提被破坏，不是技术失效。技术再好，前提坏了照样归零。
