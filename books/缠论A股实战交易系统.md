> 依据《缠中说禅教你炒股票108课》整理，针对 A 股规则（只能做多、T+1、涨跌停）适配。

> 使用方法：**新手只看"上篇"，照做即可**；能熟练划分中枢、判断背驰后，再进入"下篇"完整版。

# 上篇：直观执行版（看图 10 秒能回答"是/否"）

## 你只需要看三样东西

| 工具 | 设置 | 用途 |
|---|---|---|
| 两条均线 | 5 日线（快线）、10 日线（慢线） | 判断多空、找买卖点 |
| 一根年线 | 250 日线 | 牛熊分界，选股用 |
| 一个指标 | MACD（默认参数 12,26,9） | 看 0 轴定环境，看红绿柱定力度 |

其他指标全部关掉。

## 一、总开关：今天能不能买股票？

打开软件先看**上证指数日线图的 MACD**：

- 黄白线在 **0 轴上方** → 今天允许买。
- 黄白线在 **0 轴下方** → 今天只许卖，不许买，任何股票都不例外。

这一条就是缠师的"防狼术"（课103），能躲过所有大级别下跌。

## 二、选股：股票池入场券（四个"是"）

同时满足才进自选池（最多 10 只）：

1. 股价在 **250 日线上方**；
2. 年线**走平或开始上拐**（不再向下斜）；
3. 不是 ST，上市满半年；
4. 最近一年涨幅**没超过 100%**（不接盘）。

任何一条不满足 → 删除自选，不看第二眼。

（这是简版入场券；完整的"四道过滤"选股流程见下篇第 2 节。）

## 三、买点：只认两张图，出现才出手

### 图形一：上升回踩（对应缠论第二类买点）

```
   上涨段          缩量回调         重新起涨
  ╱╱╱╱╱         ╲╲╲            ╱
            快线(⑤)压回慢线(⑩)附近止跌
                              ↑ 今天：放量阳线收复⑤日线 = 买
 ════════════════════════════════  年线远在下方
```

买入前五问，**全部答"是"**才买：

1. 股价在年线上方，年线不再下行？
2. ⑤日线在⑩日线上方（多头排列没坏）？
3. 这次回调明显**缩量**（量能比上涨段小一半以上）？
4. 回调在⑩日线附近止跌，没有连续两天收在⑩日线下方？
5. 今天放量收阳、站回⑤日线？

### 图形二：突破回抽（对应缠论第三类买点）

```
  横盘平台(≥3周)/年线
  ═══════════════╗  ←── 放量大阳突破
                 ╚═══╲___   ←── 缩量回抽，不破平台上沿
                        ↗  ←── 重新放量起涨 = 买
```

买入前五问：

1. 前面有一个横盘 3 周以上的平台（或年线压制）？
2. 一根**放量大阳线**（量 ≥ 前 5 日均量 2 倍）突破了它？
3. 突破后回抽了几天，**缩量**？
4. 回抽的最低价**没跌破**平台上沿/年线？
5. 今天重新放量上涨？

### 下单规则（T+1 专项）

- **只在 14:45–14:55 买入**。当天买了卖不掉，尾盘买把"当天被套"的风险压到最小。
- 早上出现再好的信号，也只记不买。

## 四、卖出：每天收盘后问自己三句话

| 问 | 答"是"就执行 |
|---|---|
| ① 买入理由还在吗？（回抽低点 / 平台上沿被跌破 = 理由没了） | 明天逢反抽**清仓**，不问盈亏 |
| ② 今天收盘跌破⑩日线了吗？ | 明天**清仓** |
| ③ 股价创新高，但 MACD 红柱比前一波**明显矮**（约矮一半），且今天长上影或大阴线？ | 先**减半**；⑤日线下穿⑩日线收不回 → **清仓** |

三条之外任何情况：**拿着不动**——这就是"没有卖点就持有"。

两个铁则：

- **宁可卖早，不可卖晚**：卖错了等新买点接回，不丢人。
- **绝不在暴跌当天恐慌砍仓**：卖点是涨出来的；暴跌中等反抽再卖。

## 五、仓位：照数字执行

| 项目 | 数字 |
|---|---|
| 单只股票第一笔 | 总资金的 **1/6** |
| 浮盈且图形完好时补仓 | 加到 **1/3** 封顶 |
| 同时持股 | 最多 **2 只** |
| 现金底线 | 永远留 **1/3** |
| 总开关关闭期间 | 仓位 **0**，只卖不买 |
| 加钱 | 第一笔钱没赚到 20% 之前，**一分不加** |

## 六、绝对不做（六条禁令）

1. 不买当天涨幅超过 5% 的股票（不追高）；
2. 不补仓摊低成本（买错了就认错，反抽离场）；
3. 不碰跌停股、不买连续一字板；
4. 不在早盘买入；
5. 不听消息、不加群、不用别人的"内幕"；
6. 不同时持有超过 2 只股票。

## 七、每日操作卡

- **盘前 2 分钟**：看大盘 MACD 在 0 轴上还是下 → 写下"今天能买 / 今天只卖"。
- **盘中**：不操作、不临时改主意。
- **14:45**：翻自选池，有没有股票满足"图形一"或"图形二"的五问？有 → 按仓位买。
- **收盘后 10 分钟**：对持仓问"卖出三句话"；记账——买了什么、依据哪张图、退出线画在哪。

## 八、上手路径

1. **第 1–2 周**：只看不买。每天收盘后从自选股里找符合两张图形的股票，截图存档，事后验证。
2. **第 3–6 周**：模拟盘完整执行。目标不是赚钱，是**连续 20 笔交易 100% 按规则执行**。
3. **第 7 周起**：不超过 1 万元实盘。稳定执行 3 个月，再谈加钱。

# 下篇：完整版（进阶）

## 0. 设计前提

- 市场：A 股，只能做多，T+1，有涨跌停。
- 级别：**操作级别 = 日线**（买卖决策）；**精确级别 = 30 分钟**（区间套定位介入点）；**方向级别 = 周线**（定多空大方向）。

## 1. 市场环境过滤

- 大盘日线 MACD 黄白线在 0 轴下方 → 停止开新仓，只卖不买（课103）。
- 深沪指数背离（一个创新高、一个不肯创新高）→ 警报，收紧仓位（课13回复）。

## 2. 选股系统：从 5000 只到 2 只

> 总原则（课8、10）：选股不是选"好股票"，是选"**当下能搞的**"股票——"市场里所有亏损，都是因为持有了不能搞的股票而造成的"。能搞是会变的，所以池子必须动态维护。
> 方法（课9）：三个**互相独立**的过滤程序串联，任一不过关即淘汰——技术面 × 板块比价 × 基本面（人性），失败率相乘。

### 第一道：时机过滤（什么环境选什么股）

| 市场环境 | 优先选 |
|---|---|
| 牛市第一阶段 | 成分股/大盘股（大盘股启动骗线少，课7、10） |
| 牛市第二阶段 | 成长股（课48回复） |
| 大跌/暴跌之后 | 逆市不跌的股（课10回复）；跌到年线/半年线等关键位的（课57）；即将形成第三类买点的（课32） |
| 震荡市抢反弹 | 指标股 + 跌得多且背驰的（课26回复） |

### 第二道：技术形态过滤

入场券（四条全"是"，同上篇）：年线上方、年线走平上拐、非 ST 上市满半年、近一年涨幅未超 100%。

加分形态（原文给出的"黑马"画像，满足越多越好）：

1. 放量突破上市首日最高价的次新股（课7）；
2. 放量突破年线、随后缩量回抽年线的老股（课7）；
3. 年线走平后刚出现向上拐点（课7）；
4. 底部平台横盘充分（数周以上）后重新有启动迹象，10 元上下的二线股尤佳（课38、39回复）；
5. 利空不跌：报坏业绩却不跌反涨——说明有资金在接（课48回复）；反之，业绩特别好却走出货形态的，回避；
6. 先于大盘走强、但只"稍微先一点"的（完全逆着大盘的可能补跌，课98）。

### 第三道：板块与比价过滤（课33回复、课106）

- 只在**刚开始走强**的板块里选：板块内个股大多刚站上年线、周线尚未拉升；
- 板块内部按"先一线龙头、后二线"的顺序选，三线股不碰（三线齐动往往接近板块大调整，课38回复）；
- 简单做法：把候选股按"本次反弹还没攻克的最小周期均线"分强弱类别，优先选强势类别里还没加速的（课106）。

### 第四道：基本面（人性面）过滤（课9、73）

- 不研究财报细节，只判断两件事：有没有可讲的政策/题材"由头"？有没有让股价跌不动的人为理由（如对掌舵者行事风格的了解）？
- 远离长期没有大级别上涨（季线中枢上移）可能的行业和个股（课73）；
- 同一板块里，优先龙头或未来可能超越龙头的（课73）。

### 股票池的维护与使用（课33、46回复）

- 池子 10–30 只，覆盖 2–3 个板块，**节奏错位**（有的刚突破、有的正在回抽、有的还在蓄势）；
- 每天只在池子里找买点；出掉一只，马上在池子里找下一只接档；
- 走坏的（跌破年线 / 买入结构破坏）立即踢出，每周换入新符合条件的；
- 每次实际持股不超过 2 只。

### 落地流程

- **周末 30 分钟**：板块强弱排序 → 圈定 2–3 个板块 → 板块内按入场券筛 → 按加分形态排序 → 更新股票池；
- **每日收盘**：只在池内过"图形一/图形二"的五问，全"是"的进入次日尾盘买入候选。

## 3. 买入系统（三个买点，按优先级）

**买点 A：日线第二类买点（主战场）**
1. 前面出现日线底背驰一买：最后一段下跌的 MACD 绿柱面积明显小于前一段，且黄白线曾回拉 0 轴；
2. 随后反弹、再次回抽**不创新低**（或创新低但次级别盘整背驰）；
3. 在 30 分钟图上用区间套找到回抽段底背驰 / 底分型确认 → 介入。

**买点 B：日线第三类买点（进攻型）**
- 股价向上离开中枢后，第一次回抽不破 ZG（中枢上沿），30 分钟底背驰确认 → 介入。
- 只做**第一个中枢**的三买（课79）；第二个中枢以后的三买放弃。
- 简单替代形态：**放量突破年线后缩量回抽年线不破**（课7）——实战中常与三买重合，二三买重合是最强形态（课21）。

**买点 C：中枢震荡下沿买点（降成本型）**
- 只对已持仓股票：中枢震荡下沿（接近 ZD）次级别底背驰时回补，上沿（接近 ZG）顶背驰时减。**先卖后买**。

**介入程序**：30 分钟底分型确认后，下午 14:30 后建仓；首仓 1/2，次日买点结构未破坏再补足。

## 4. 卖出系统（镜像 + 机械底线）

触发**任一**条件即执行：

| 触发 | 动作 |
|---|---|
| 买入逻辑失效（回抽跌回中枢 / 跌破一买低点 / 有效跌破年线） | 反弹中清仓——这是"能搞变不能搞"，不是止损（课13） |
| 日线顶分型 + 30 分钟顶背驰 | 减半 |
| 日线趋势背驰（红柱面积 < 前段，黄白线回拉后不创新高） | 清仓（第一类卖点） |
| 跌破中枢后反抽不回中枢（第三类卖点） | 无条件清仓——"最后的、被理论保障的离开机会"（课47） |
| 机械底线（新手） | 收盘有效跌破⑩日线 → 走；盘中跌破买点最低点 → 次日反抽走 |

纪律：卖点是在上涨中出现的，禁止在暴跌中恐慌砍仓（课57）；宁可卖早、决不卖晚（课54）。

## 5. 仓位与资金管理

- 总资金分三份：**底仓（中线）+ 波段仓 + 机动仓（≤10% 打短差）**；新手前半年不做短差。
- 单股 ≤ 总资金 1/3；同时持股 ≤ 3 只（课16回复）。
- 绝不追高：只在回抽、回调、震荡下沿买；错过就等下一个买点（课10回复）。
- **成本归零计划**（课31）：个股涨幅接近翻倍时找大级别卖点卖出一半、收回本金；此后每次短差盈利全部换筹码，让 0 成本股票越来越多。
- 绝不增资、绝不借贷：第一笔钱没赚到钱之前，一分不加（课95、96）。

## 6. A 股特殊条款

- **T+1**：任何买入默认承担隔夜风险 → 不早盘追买；重大利空次日跌破结构，按失效条款处理。
- **涨跌停**：跌停卖不出是系统性风险 → 仓位控制是唯一解；涨停不排队追。
- **政策风险**（课74）：泡沫化阶段只战略性持有、不再战略性买入；硬调控出台后逢一切反弹离场。
- **停牌**：单股仓位上限即停牌风险上限。

## 7. 日常流程

1. 盘前（5 分钟）：看大盘 0 轴状态 → 决定今天允不允许买。
2. 盘中：只执行计划，不临时决策。
3. 收盘后（10 分钟，课42）：复盘股票池——谁出现了买卖点结构？记录每笔交易：买点类型、级别、失效位、计划。
4. 周末：周线图过一遍股票池，更新中枢位置与板块强弱。
