# 《缠中说禅教你炒股票108课》研读总结

> 此文档内容不一定准确

---

## 一句话总纲

**不预测，只分类；买点买，卖点卖；成本变零，天下无敌。**

全部 108 课，本质上是把这一句话展开成一套可严格执行的体系。

---

## 一、世界观层：不测而测（课17、68、96–100、105）

- 走势**不可预测，但可以完全分类**。对每种分类预设好应对，让市场自己选——"所有相应的对策都事先有了，只等市场触及我们事先给定的开关"（课98）。
- 理论基石是**走势终完美**：任何级别的任何走势类型必然完成（课17）。严格表述为**唯一分解定理**：任何走势可唯一分解为 `a1A1+a5A5+a30A30…` 的形式（课101、102）。
- 一切分析的前提是**级别**："离开级别，无所谓趋势；没有趋势，没有背驰"（课16回复）。级别 = 显微镜倍数，与时间周期无必然关系（课63、84）。
- 反赌徒心理：不预设目标位、不因为"怕错过"而动手（课96）。分类标准不重要，**完全分类**才重要（课105）。

## 二、形态学层：递归几何链（课62–83，纯几何，无须任何前提）

| 层级 | 定义要点 | 出处 |
|---|---|---|
| K线包含处理 | 向上取"高高"，向下取"低低"，按时间顺序合并 | 课62、65 |
| 分型 | 顶分型：中间K线高点、低点均为三根中最高；底分型反之 | 课62 |
| 笔 | 相邻顶底 + 至少一根独立K线；顶底必须交替 | 课62、65、77 |
| 线段 | 至少三笔且前三笔有重叠；结束判据 = 特征序列分型（分有缺口/无缺口两种情况） | 课65、67、71、77、78 |
| 中枢 | 至少三个连续次级别走势的重叠区间；ZG=min(g1,g2)，ZD=max(d1,d2) | 课17、18、20 |
| 走势类型 | 盘整 = 只含一个中枢；趋势 = 含两个以上同向中枢 | 课17 |

- 中枢只有三种命运：**延伸、扩展、新生**（课23回复）；延伸超 9 段自动升级为更大级别中枢（课33）。
- 中枢定理三：中枢被破坏，当且仅当次级别离开后次级别回抽不再回到中枢内（课18）。

## 三、动力学层：背驰（课15、24、27、37、43、44）

- **背驰 = 趋势力度衰减**：比较围绕同一中枢的两段同向走势。
- MACD 辅助标准（课24）：连接段 B 把黄白线（DIF/DEA）拉回 0 轴附近，C 段创新高（低）但**柱子面积明显小于 A 段**，即背驰。
- 铁律：**没有趋势，没有背驰**；c 段必须是次级别、必须创新高（低）、b 级别不能大于 c（课37）。
- **区间套**（课27、61）：大级别背驰段 → 次级别背驰段 → 层层下钻，转折点可精确定位到一笔成交。
- 小转大定理（课44）：小级别背驰引发大级别转折的必要条件，是最后一个次级别中枢出现第三类买卖点。
- 背驰后只有三种演化：最后中枢级别扩展 / 更大级别盘整 / 反趋势（背驰-转折定理，课29）。

## 四、买卖点层：完备的三类买卖点（课12–14、20、21、53、101）

| 类别 | 定义 | 性质 |
|---|---|---|
| 第一类买点 | 下跌趋势最后一个中枢之后的**背驰点** | 最暴利，最难当下确认 |
| 第二类买点 | 一买之后第一次次级别回抽的低点 | 一买的补充与确认；小转大时是最佳买点 |
| 第三类买点 | 次级别向上离开中枢 + 次级别回抽**不跌回中枢区间**（ZG 上方） | 后知后觉但最省时；牛市爆发力最强 |

卖点完全镜像（一卖 = 顶背驰点；二卖 = 反抽不创新高；三卖 = 跌破中枢后回抽不回）。

- **完备性定理**（课21）：市场中任何上涨与下跌，都必然从三类买卖点中的某一类开始并结束。
- **买卖点定律**（课14、17）：大级别第二类买点 = 次级别第一类买点；一切买点最终归结到不同级别的第一类买点。
- 二、三类买点重合是最强形态，其后往往出现大级别上涨（课21）。
- 纪律："任何不在这两个买点买入的行为都是不可以原谅的，因为这是原则的错误，而不是高低的区别"（课12）。

## 五、操作与资金层

**操作模式**
- **利润率最大定理**（课49）：固定级别下，只参与盘整与上涨——中枢震荡降成本（上沿减、下沿增、先卖后买），三类买点后持股待涨不做短差，中枢上移背驰后全抛。
- **机械化操作**（课38、39）：同级别分解 + 相邻同向段盘整背驰比较（i 与 i+2 比较），构成完全机械的买卖程式，可自动换档升级（课40）。
- **短差程序**（课14）：大级别买点介入，次级别第一类卖点减仓，次级别第一类买点回补。
- **底部三段节奏**（课108）：底、顶、连接段；两头做中枢震荡（底部先买后卖、顶部先卖后买），中间持有。
- **反弹操作**（课107）：30 分钟反弹按 5 分钟节奏分段处理；第一中枢后出现三买 + 非背驰拉升，才"坐轿子"。

**资金管理**
- 无压力、无期限资金；绝不借贷、绝不增资——"100 万都搞不好，难道想搞 100 万的平方？"（课31、95）。
- 核心程式：**成本变 0，然后挣股票**（课31）——翻倍附近找大级别卖点出一半收回本金，此后短差盈利全部换筹码。
- 仓位与级别匹配；小资金持股不超过 2–3 只（课16回复、课40回复）。

**风险控制**
- 缠论没有"止损"概念，只有"**能搞变不能搞**"（课13）：买入逻辑失效即退出，与盈亏无关。
- 最低保障 = **防狼术**（课103）：MACD 黄白线在 0 轴下方的市场和股票，一律远离。
- 政策风险九条（课74）：政策只是中短期分力；泡沫阶段只战略性持有；硬调控出台后逢反弹离场。

## 六、心态与纪律（课41、80、96 等）

- "市场的节奏只有一个：买点买、卖点卖"（课41）。阻碍你的是贪婪与恐惧——"买点总在下跌中形成，卖点总在上涨中形成"。
- 绝不追涨杀跌；绝不按盈亏进出；对股票没有感情，只对买卖点有感情。
- "宁愿卖早，决不卖晚"（课54）；"只要赚钱就没有卖错"（课57）。
- 钢铁战士七条（课80）：买错比卖错严重，确认买错手起刀落；二类买卖点是第一次改错机会，三类是第二次。
- 每天收盘后花 10 分钟复盘当天操作与心理过程（课42）。

## 七、对 A 股的专门论述

- **T+1**：操作级别不能太小，新手不小于 30 分钟、最好日线（课35、41、53）；背驰买入要选**先于大盘走强**的股，留隔夜退出空间（课98）；下午出现的买点胆子可以大点（课94）。
- **只能做多**：卖点之后持币等待，与持股同等重要（课45）。
- **板块轮动**：一、二、三线依次启动，三线齐动接近大调整（课38回复）；用"板块强弱指标"（板块内个股均线类别数的平均值）看轮动次序（课106）。
- **选股三个独立程序**（乘法原则，课9）：技术面 + 比价关系/板块 + 基本面（对人性的了解），总失败率 = 各环节失败率相乘。选股方法散见各课：课7（年线/新股黑马法）、课8（能搞/不能搞分类）、课32（大跌找三买）、课33回复（股票池管理）、课38–39回复（二线股）、课48回复（利空不跌出黑马）、课57（暴跌关键位反弹）、课60（个股形态四分类）、课73（龙头组合）、课98（先于大盘）、课106（板块强弱指标）。完整选股流程见《缠论A股实战交易系统.md》下篇第 2 节。
