# 用户发现课程图示的标注错误：X1 被画在向上的笔上

2026-10-14，第3课（线段·特征序列）发布后，用户指出图中 "X1 不是向上的笔吗?"——他看出标注在向上的笔上的 X 标签是错的。

证据：这要求用户同时掌握两件事——X 代表向下笔、且特征序列的方向必须与线段相反。他是在明知图和文字规则冲突时选择相信规则，并主动质疑材料。课程确有 bug（seg 标签整体错位一段），已修复并重新发布。

意义：这条规则不再需要重教；同时提示该用户会逐图核对定义，后面的课程可以适度加大图形复杂度（他会挑错，就让他挑）。另：未来课程发布前，图示标签必须程序化回归验证（已在 charts.js 的 seg 语义上补充文档，防止同类错误）。
